# GANVESYS TECHNOLOGIES — ₹0 Temporary Deployment

This package is prepared for a temporary public deployment using **Netlify Free** for the Next.js application and a free PostgreSQL service for the lead database.

## What was prepared

- Next.js deployment configuration for Netlify
- SEO metadata, canonical URL and Open Graph metadata
- `robots.txt` generated by Next.js
- `sitemap.xml` generated by Next.js
- Organization JSON-LD structured data
- Google-friendly indexable public pages
- `/admin` and `/api/` excluded from crawling
- Lead-list API protected by the signed session
- Admin statistics API protected by the signed session
- `.gitignore` protection for `.env` and build files
- Next.js upgraded to the current supported security release line used for this deployment plan (`15.5.27`)

## Step 1 — GitHub

Create a **private** repository and upload this project. Never upload `.env` or real passwords.

Recommended repository name:

`GANVESYS-TECHNOLOGIES`

## Step 2 — Netlify

1. Create/sign in to Netlify.
2. Add new project → Import an existing project.
3. Connect GitHub.
4. Select `GANVESYS-TECHNOLOGIES`.
5. Build command: `npm run build`.
6. Netlify detects Next.js automatically.
7. Publish/deploy.

Netlify provides a temporary URL similar to:

`https://your-site-name.netlify.app`

## Step 3 — PostgreSQL

For a temporary ₹0 setup, use a free PostgreSQL provider. A Render Free Postgres database can be used for testing, but Render currently states that free Postgres databases expire after 30 days and should not be used for production.

After creating the database, copy its PostgreSQL connection string into Netlify environment variables.

## Step 4 — Netlify environment variables

Set these in Netlify:

`DATABASE_URL` = your PostgreSQL connection string

`AUTH_SECRET` = a long random secret (32+ bytes)

`ADMIN_EMAIL` = your real admin email

`ADMIN_PASSWORD` = a strong temporary admin password

`NEXT_PUBLIC_SITE_URL` = your exact Netlify URL, for example:

`https://your-site-name.netlify.app`

Also set:

`NETLIFY_NEXT_SKEW_PROTECTION=true`

## Step 5 — Initialize the database

After the database exists, run from your local project folder with the production `DATABASE_URL` temporarily supplied in your shell:

```bash
npm install
npx prisma generate
npx prisma db push
npm run db:seed
```

Then deploy/redeploy on Netlify.

**Do not commit the database URL or admin password.**

## Step 6 — Google indexing

Once the Netlify URL works:

1. Open Google Search Console.
2. Add the exact Netlify URL as a URL-prefix property.
3. Verify ownership using the available verification method.
4. Submit:

`https://your-site-name.netlify.app/sitemap.xml`

5. Inspect the homepage URL.
6. Click **Request indexing**.
7. Repeat for the important public pages if needed.

Google does not guarantee immediate indexing or ranking. The sitemap and indexing request only help Google discover and process the pages.

## Important

This is a temporary free deployment. The Render Free PostgreSQL option has a 30-day expiry. Before using the site as a real business production system, move the database to a persistent paid/production database and review authentication, rate limiting, MFA, backups, monitoring and email delivery.
